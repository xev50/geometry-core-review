# Geometry & Algebra Core Study Guide

A static web project designed to organize and review fundamental mathematics concepts. This repository serves as a personal study portal for core geometry and algebra topics.

## Overview
This site was built to compile coursework notes into a clean, easy-to-read digital format. It covers essential high school math fundamentals, making it easier to reference formulas and concepts without flipping through a textbook.

## Features
*   **Core Theorems:** Quick reference for the Pythagorean theorem and geometric proofs.
*   **Formula Archive:** Dedicated sections for area, circumference, and basic equations.
*   **Trigonometry Basics:** SOH CAH TOA reference guide.
*   **Distraction-Free UI:** Built with pure HTML and CSS for fast loading and straightforward reading.
